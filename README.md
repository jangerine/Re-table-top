# 테이블탑 시뮬레이터 (모바일 · 실시간 멀티플레이)

Node.js(Express + Socket.io) 백엔드와 순수 HTML/JS 프론트엔드로 만든 범용 테이블탑 엔진입니다.

## 현재 구현된 기능
- 방 코드로 입장/생성, 실시간 상태 동기화
- 주사위 굴리기 (d4/d6/d8/d10/d12/d20 + 커스텀 개수·면수), 모두에게 결과 로그 표시
- 보드 위 말(토큰) 추가 및 드래그 이동 (색상 선택)
- 카드 덱: 기본 트럼프 52장 / 번호카드 1~20 생성, 셔플, 드로우
- 손패 → 보드로 카드 내기(드래그 또는 탭), 보드 카드 탭으로 뒤집기, 손패 쪽으로 끌면 버림더미로 이동
- 보드 확대/축소(핀치줌·휠) 및 한 손가락 팬(이동), 우하단 버튼으로 화면 리셋 — 플레이어마다 독립적인 화면
- 보드 배경 이미지 업로드(방 전체에 공유, 자동으로 리사이즈해서 전송)
- 말/카드를 두 손가락으로 비틀면 회전 (좌표는 그대로, 각도만 바뀜)
- 말/카드를 다른 말/카드 위에 겹쳐 놓으면 더미(스택)로 합쳐짐 — 탭하면 맨 위 한 개만 꺼내지고, 통째로 드래그하면 더미 전체가 이동
- 터치(모바일)와 마우스 모두 Pointer Events로 통합 지원, 좌표는 %기반이라 화면 크기에 상관없이 동기화됨

## 로컬 실행
```bash
npm install
npm start
```
브라우저에서 http://localhost:3000 접속 (같은 방 코드로 여러 탭/기기에서 입장하면 동기화됩니다).

## Render 배포
1. https://render.com 에서 New → Web Service
2. 방금 만든 GitHub 저장소 연결
3. 설정값
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free로 시작 가능 (단, 무료 플랜은 일정 시간 미사용 시 슬립 상태가 되어 첫 접속이 느릴 수 있음)
4. 배포 완료 후 받은 `https://xxxx.onrender.com` 주소를 모바일 브라우저에서 열면 바로 사용 가능
